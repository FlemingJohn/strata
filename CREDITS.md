# Artwork credits

## Player character

Sprites from the **Liberated Pixel Cup** (LPC), taken from the
[Universal LPC Spritesheet Character Generator](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator).

Layers used:

| Layer | Path in the LPC repository |
| --- | --- |
| Body | body/bodies/male |
| Head | head/heads/human/male |
| Trousers | legs/pantaloons/male |
| Boots | feet/boots/fold/male |
| Tunic | torso/clothes/longsleeve/longsleeve/male |
| Hood | hat/cloth/hood/adult |

Animations used: idle, walk, slash, backslash, thrust, hurt.
